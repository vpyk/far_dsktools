## Функциональность

- [x] **Меню настроек** (`ConfigureW`): открытие образов по Enter/Ctrl+PgDn, маска файлов и флажки файловых систем для этого (неподходящий файл отдаётся FAR — другим плагинам или его собственному Enter), разрешение записи, резервная копия `.bak`. Образ с нераспознанной ФС по Enter тоже отдаётся FAR (раньше — ошибка «Неподдерживаемая файловая система»).
- [ ] **Другие настройки (предложено):** префикс командной строки; пункт в меню F11; колонка «Тип» и режим панели при открытии; показ удалённых файлов (и восстановление); области CP/M папками или списком; запоминание опций копирования; кодировка имён CP/M без `charmap`; краткая/полная информационная панель.
- [x] **Справка (F1)** — одна тема: возможности плагина и клавиши (`src/DskTools{Eng,Rus}.hlf`).
- [ ] **Справка — подробнее:** форматы и ФС с указанием, что можно записывать; диалог копирования и его опции; области CP/M; информационная панель; ссылки на темы из диалогов (`HelpTopic`).
- [x] **Тип файла в панели** — колонка «Тип» (`type_label`) в режимах «Полный» (Ctrl+3) и «Широкий» (Ctrl+4) для ФС с типами: DOS 3.3 (B/A/T…), ProDOS, Onix, Искра-226, атрибуты CP/M (S/A) и FAT (R/H/S/A).
- [x] **Информационная панель (Ctrl+L)** — образ (файл, формат, тип, ФС, том, запись разрешена / почему нет), место (`get_stats()`, также `FreeSize` в строке состояния панели) и `information()` ФС с подписями из DISK Commander на двух языках.
- [ ] **Информационная панель — отбор и формат параметров.** Для некоторых ФС `information()` слишком подробна: строки не помещаются ни по числу, ни по длине, у части параметров неудобный формат (служебные байты VTOC `[$00]: $04`, шестнадцатеричные списки и т. п.). Выбрать, что показывать по каждой ФС, и как форматировать (возможно, свой набор вместо полного `information()`, а полный вывод — отдельно).
- [x] **Запись в образ** (F5/F6 в образ, F8, F7, F6 из образа) для сырых образов (`FILE_RAW_MSB`, размер файла = размер образа) с ФС CP/M, DOS 3.3, FAT, RT-11. Образ сохраняется сразу после операции (временный файл + `ReplaceFileW`); при ошибке сохранения изменения отбрасываются перечитыванием образа. Имена, не подходящие ФС, — ошибка с пропуском.
- [x] **Резервная копия `.bak`** перед первым изменением образа в панели (настройка, по умолчанию выключена; `<образ>.bak` перезаписывается).
- [ ] **Запись HFE и MFM/NIB/NIC.** Writer'ы dsk_tools перекодируют все дорожки заново — без резервной копии можно потерять нестандартные дорожки/защиту. Сейчас такие образы только для чтения.
- [ ] **Сырые образы с заголовком** (Агат 143360+128, `.rtd` с заголовком 256 байт) — только для чтения: `WriterRAW` пишет буфер без заголовка. Можно сохранять заголовок из исходного файла.
- [ ] **AIM, IMD, FIL** — writer'а нет; возможна запись только «сохранить как» в другой формат.
- [x] **Переименование (Shift+F6)** в образе (CP/M, DOS 3.3, FAT, RT-11): текущий элемент, курсор на новое имя; совпадение с существующим именем и длинное имя DOS 3.3 проверяет плагин. Области `USER_nn` не переименовываются.
- [ ] **CP/M: проверка имён в dsk_tools** — `put_file` и `rename_file` проверяют только длину 8.3: символы `*?.,:;=<>[]|` и пробел проходят, не-ASCII пишется байтами UTF-8 (без `charmap`), `rename_file` не ищет совпадение имени. Возможный патч upstream.
- [x] **Shift+F5** — копия текущего файла или каталога (с содержимым) в том же каталоге образа под новым именем; атрибуты, даты, тип DOS 3.3, область CP/M сохраняются. Проверено на библиотеке (FAT, CP/M, RT-11).
- [ ] **Патч для dsk_tools: `uf.fs` в `dir()`** — CP/M (обе ветки), Sprite OS, Iskra-226, FIL не заполняют `UniversalFile::fs` (поле не инициализировано), поэтому, например, `put_file` CP/M не узнаёт CP/M-источник и пишет в область 0. Плагин обходит это сам (`copy_proto()`). Патч `patches/0001-CP-M-Sprite-OS-Iskra-226-dir-sets-UniversalFile-fs.patch` (FIL только обнуляется: его `get_fs()` — DOS33, а метаданных DOS 3.3 нет) — ждёт принятия.
- [ ] **Патч для dsk_tools: DOS 3.3 `mkdir` в родном режиме** — копирует в имя байты с начала записи каталога (`&metadata->dir_entry` вместо `.name`). Патч `patches/0002-DOS-3.3-mkdir-of-a-DOS-3.3-directory-took-its-name-f.patch` — ждёт принятия. Плагин обходит это сам (каталоги DOS 3.3 создаются по имени).
- [x] **CP/M: запись в область USER.** F7 в корне создаёт пустой `USER_nn` (в памяти, до первого файла); F5 в `USER_nn` пишет с `UniversalFile{fs = FS::CPM, attributes = n << 8}`; F8 на `USER_nn` удаляет всю область.
- [x] **Один образ в двух панелях** — перед каждой операцией и при перерисовке панель перечитывает образ, если файл изменился (другая панель — счётчик сохранений, другая программа — время и размер файла); элементы, переданные FAR, ищутся по имени. Раньше F6 между двумя панелями одного образа терял перенесённые файлы.
- [x] **CP/M: смена области у файла** — через `file_set_metadata({"user": n})` (меняет ST во всех экстентах, атрибуты сохраняются; совпадение имени в целевой области не проверяет — проверять в плагине). Сделано: F6 между двумя панелями одного образа — смена области у выделенных файлов без временной папки (атрибуты и имена сохраняются, совпадающий файл в целевой области — с вопросом о замене); проверено в FAR, **не проверено на кириллических именах** (образ Корвета). Alt+F6 — то же с выбором области из списка (по умолчанию — область другой панели того же образа).
- [ ] **CP/M: путь в Shift+F6 для смены области** (`USER_05\`, `..\USER_05\NEW.TXT`, `..\`) — сделано и откатено: малейшее отклонение от синтаксиса (пропущенный символ или слэш) молча отправляет файл не туда. Если вернуться — с проверкой и подтверждением, куда именно уйдёт файл.
- [ ] **CP/M: «Область» вместо «<Папка>» у `USER_nn`.** FAR сам пишет «<Папка>» в колонке размера у каталогов, подменить нельзя. Возможно: на панелях CP/M в режимах 3/4 своя колонка `C1` вместо `S` (размер файлов выровнен вправо, у областей — «Область»), также в строке состояния; не учитывает Ctrl+Shift+S и разделители разрядов. Или проще — «Область» в колонке «Тип». Отложено.
- [ ] **Просмотр с конвертацией.** dsk_tools умеет детокенизировать BASIC и перекодировать тексты (viewers, charmaps) — можно отдавать на F3 читаемый вариант вместо сырых байтов.
